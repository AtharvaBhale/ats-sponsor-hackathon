## Script (about 4:30)
1. **0:00 What and why (20s).** Resumes are sensitive and ATS tools reward keyword stuffing.
   This tool tailors honestly, locally, and checks the job is real.
2. **0:20 Codespaces + local model (30s).** Show the Codespace, `make run`, `make model`
   (13.8 tok/s), Ports tab. Say: qwen2.5:1.5b, CPU only, nothing leaves the machine.
3. **0:50 Job verification (45s).** Paste a live Greenhouse URL, Fetch & verify: `live`,
   JD loaded, sponsorship tier, staffing badge. Then the closed URL: `closed`; show purge.
4. **1:35 Tailor, positive case (60s).** Sample resume + matching job, click Tailor. Point out
   accepted bullets with "Added keywords", kept originals, the gap question. Type a real
   course project, Draft bullet, Add to resume. Preview updates.
5. **2:35 Truthfulness, negative cases (50s).** Unrelated finance job: weak-match banner, no
   changes. Then show a blocked rewrite with its reason (invented number or dropped skill).
6. **3:25 Uploads and export (25s).** Upload a transcript: irrelevant lines and IDs dropped.
   Download PDF and plain text.
7. **3:50 Sponsorship (20s).** `check_tier.py`: Google and Microsoft Proven; Amazon Unknown
   with similar filers (explain why Unknown is honest).
8. **4:10 Limitations (20s).** No OCR, 1.5B quality, Workday, no real DOL file, map not built,
   live URL needs a running Codespace.

Record from a warm model (run one Tailor first) and use only the fictional resume.
